# 无线预览传输优化开发方案

任务 ID：NET-20261016-01；日期：2026-10-16（北京时间）；会话：`01a13477-9b6f-7f43-8a41-5e5b77886c15`。

本仓工作分支 `perf/wireless-network-load-20261016`，依赖未合并 `docs/gimbal-startup-diagnosis-20261016@9201cd8016be1a9456be6590a8894e7c7b95cb86`，保留媒体参数/车辆参数功能；默认main为2f4d90f58ac1bf85eb8dce4f38c0c594971dd181。跨仓方案见Tenco同任务记录和统一变更记录。

目标是在不降低预览质量参数/尺寸/帧率、不改变照片和录像保存的情况下减少MJPEG流量与小TCP包。现场revision6的640×480@15是用户设置，保护Capture和settings持久化文件。

拟只对`OakCameraDevice::encodeJpeg`预览编码启用OpenCV `IMWRITE_JPEG_OPTIMIZE`，默认启用并提供`--disable-preview-jpeg-optimization`回退选项及状态字段。优化JPEG熵编码不改变DCT量化参数；须用相同BGR输入实证解码像素相同、字节减少和CPU预算，不能把重复有损重压缩称为无损。原生照片单独编码、录像H264路径保持。

HTTP multipart每帧头/JPEG/结尾仍保持旧格式与顺序，用Linux发送提示将头和JPEG与结尾归并，避免三次独立小发送；处理EINTR/短写/超时/关闭，沿用最新帧和有界连接数。无新HTTP写接口、无需客户端升级、不变更媒体settings schema/revision。

验证与风险：优化Huffman增加编码CPU，Jetson隔离完整Release build/CTest及真实场景离线编码基准后再决定是否默认启用；生产HTTP格式/恢复/慢客户端和关停测试维持。假源不能部署或与线上争用相机。当前只读测量原服务，不停止或切换；候选哈希/短时中断和临时回退明确后按根规范确认现场部署。部署前原运行产物不清理，成功部署才按latest-only删除事务备份。
